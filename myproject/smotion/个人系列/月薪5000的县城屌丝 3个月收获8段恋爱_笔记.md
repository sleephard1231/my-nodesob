## 一句话主旨

一个 23 岁、身高 173cm／体重 150 斤、月薪 5000、没车没房、刚脱贫县城、只有圆寸没有任何「建模」的国企男生，靠**纯线上聊天技术（分期报的线上私教）**，<span style="color:#c00">在 3 个月内与 8 个女生发生关系</span>，还拿下了一个「所有国男都羡慕」的本地独女女朋友——用来反驳「没有经济、没有建模就撩不到妹」的说法。

  - 不高、不帅、没钱、在小地方，
  - 「<span style="color:#c00">你几乎集结了所有不利于 game 的因素合在一起</span>，但你依然还能拿到结果。」

## 四、案例①：跨城备考女生（19:00–31:00）

**认识渠道**：<span style="color:#c00">**火花 APP**</span>（不是积木/牵手，因为「小县城没人用，方圆 30 公里之外连条母狗都没有」）。5 月份认识，认识几个月毫无进展，用打法后**一周确认关系**。

**技术点（学员自述，讲者口径）**
- 一上来就按公子说的**聊她感兴趣的地方**：「你喜欢吃什么？」——她对吃特别感兴趣，就围绕吃展开。
- 抛邀约钩子：「我知道还有一个地方蛮好吃，有机会我带你去尝尝。」对方答「好啊」。
- 反复累积同类话题，女生逐渐「上头」，随后确认恋爱关系。
- 主播追问出的**核心判断：这是「硬聊」路线的典型**——没有钱、没有脸，只能靠把一句话抠出更多话题。

**见面细节**
- 距离：坐高铁 + 到高铁站时间，**单程约 5 小时**（主播吐槽「坐飞机去越南都用不到 5 小时」）。
- 女生当时正在备考一个「人生中特别重要的考试」，**考前不到一周**；他说「你好好备考」，女生反问「你有没有空」，然后**瞒着家里说出去玩几天，主动跑到他的城市**。
- 费用：<span style="color:#c00">**全是女生出**</span>，还给他带了很多奶茶；见面时化全妆、非常害羞。
- 流程：女生先到酒店、发房间号，说「我妆造做好了，你上来」；他一开门没人，**女生躲在门后**。
- 他没有「见光死」：女生低着头躲着，说「太害羞了，妆也没化好」。
- 他先带她出去转、买蛋糕、买花、逛街，再带回**同一家酒店**。
- 当晚「特别顺利，没有遇到任何抗拒，直接拿下」。
- 学员原话描述体验：「想做什么就做什么，完全就是他的人了，把自己全部释放得干干净净」；当晚共 **4 次**（直播用「炒了四次菜」表述）。

**回应质疑（00:25:00 左右）**
- 弹幕质疑：「你这口才，线下能调动得了妹子情绪吗？」
- 学员回答：「<span style="color:#c00">**我早就在线上把情绪调动好了，她线上就已经爱上我了，线下根本不需要调动。就算我穿个村头的衣服去见她，她也不会有反应，因为根本没有见光死。**</span>」
- 主播点评：「你这个回答让他没话说了——我没说我口才好，我是**线上打法**，线上做到位了。」

**后续与成本**
- 维持 **2 个月**，女生又来找过他 **2–3 次**；每次体验感都很好；
- 女生会给他准备睡衣、零食，他不开心时打电话安慰他；
- 成本：「**好像就订了个酒店，没花什么钱**」；
- 主播算账：「第一次见面开了个房，后面都是女生来他的城市主动找他，而且每次都是女生花钱、花时间、花精力、出身体、出感情——**这他妈才是有出息的**。」

**他凭什么吸引到她？（00:27:22）**
- 「男人的条件分外在和内在。我外在条件不行，但我有一颗**经过公子教导的、自信的心**。我遇到任何人都不胆怯，在她面前非常自信。」
- 平时和女生相处「话多一点」，女生会跟他撒娇；他在这些妹子眼里是**高价值男人**。
- 关于是否包装个人信息：**没有明显拔高**，只说了自己在哪个单位工作，对方「哦，好吧」，然后正常交换信息。
- 他的判断：「应该是**正好需要一个像我这样的男人出现，可以好好陪伴她**。很多女生不一定需要你帅、有钱、高价值，你只要找到不同类型的女人，用不同打法，就能走进她内心。」
- 小县城是优势还是劣势？主播替他总结：**「你把小县城转化成了优势——这些妹子没见过什么世面，竞争对手也不强，你在这个县城里干死了其他男的，等于降维打击。」** 学员补充：目标也不全是小地方的，也有大地方的。

**这段关系对他的意义**
- 小地方工作特别累、经常内耗，「每次去接她，都是给自己放一次假，跟他见面可以放松自己」，心态上帮助很大。
- 她说过：「你以后这么穷，还会不会喜欢我？」他答会；女生说：「**你无论变成什么样子，我都会喜欢你的。**」
- 结局：**是他不联系她了**（「我后面不联系他了」），主播追问「想联系还是可以继续良性的」，他承认可以。

## 五、案例②：长得像前任的女生 + 聊天底层逻辑（31:00–42:00）

**背景**：同样来自**火花 APP**；长得、说话方式都像他前任，他觉得「如果能有一段好的恋爱，也算弥补一下前任的遗憾」；对方家里条件不好、平时很累，需要有人懂她、走进她心里。

**学员主动给出的「干货」（31:00–34:00，本场技术含量最高的一段）**

1. **开局：只聊她感兴趣的话题**——吃喝玩乐。
2. **用话题反测窗口**：
   - 反馈好 → 窗口大 → 乘胜追击；
   - 反馈冷淡 → 给一个**高价值离场**，先撤，等她下次有窗口再进攻。
3. **从朋友圈反推切入点**：
   - 她爱发美食 → 「附近哪里的美食不错」；
   - 她照片多 → 「我也会摄影，有机会带你去拍照」。
4. **一个话题往下拆 5 个、10 个**，越聊越深；
   - 对比普通男：「别的男的只会夸一句你很好看，然后就完了；我会跟她聊得很深，能走到她内心里去，给她一种**我很懂你、我也是这种人**的感觉。」
5. <span style="color:#c00">**路径：投其所好 → 不断延伸 → 聊深 → 吸引**</span>。
6. 主播定性：「这是所有**没有经济、没有建模**的人一开始唯一的打法——因为你没有别的牌可以出，只能硬聊。」

**他的私人 SOP（34:30–36:20）**

- 核心模型：<span style="color:#c00">**追女生是 0 到 100 米一条线**</span>，根据反馈判断她在 20 米还是 50 米，用不同力度。
  - 20 米：她只回「嗨」「我也很喜欢吃」——**多找话题、多问**（生活习惯、为什么爱吃、辣不辣、能不能吃辣），并**引出自己的故事 + 加入高价值**。
  - 50 米：她开始说细节（「我晚上喜欢吃汉堡、炸鸡、火鸡面」）——**加快进度**：「那有机会我带你吃吧。」
- 主播认可这段：「这才是干货，不花里胡哨，但最实际。」并总结<span style="color:#c00">**把妹只有三条路**</span>：
  | 路径 | 说明 |
  | --- | --- |
  | 技术流 | 靠这套聊天/情绪打法 |
  | 颜值 | 长得帅 |
  | 花钱 | 直接付费 |
  - 「他前两种不用想，23 岁没什么钱、没什么阅历，**只能靠硬聊**——硬聊就是把一句话抠出更多话题，这有什么问题？」

**这个女生怎么搞定（37:00–38:00）**
- 初期反馈特别好，**得益于公子指导拍的展示面**——妹子愿意回消息、有基本兴趣值。
- 流程：先交换基本信息（在哪、做什么）→ 聊兴趣爱好 → 再往**人生价值观**延伸。
- <span style="color:#c00">**两天搞定**（确认关系）</span>。
- 主播质疑：「你才 23 岁、没什么阅历，怎么聊人生观价值观？」学员解释：不是宏大叙事，而是**适配对方的小话题**：
  - 「你觉得两个人在一起最重要的是什么？」
  - 「你觉得最浪漫的事情是什么？」
  - 「如果我以后生病了，你会不会照顾我？」
  - 女生反馈特别好，「她会配合我，关系一点点往前推进」。

**未完成的部分**
- 确认关系后女生让他去找她，但她在**另一个县城**，太远，他没去，女生不开心；他承诺「下个月去找你」，对方说「真的吗？那你一定要来」。
- 主播问「为什么有自信见面就能收尾」：因为**线上已经聊到定酒店、做好了预期**——「如果到时候你太可爱了，我听你的话，你会不会打我呀？」对方说不会；还描述了见面后一起上班、一起散步的场景。
- 结论：<span style="color:#c00">**线上把见面后要发生的细节提前铺垫完，线下只是执行。**</span>

> ⚠️ 主播此处提醒定义：「微信上确定关系不算搞定，<span style="color:#c00">**真正的肢体链接才叫搞定**</span>。」

## 六、为什么 20 天就「通了」（42:00–47:30）

- **8 月 9 日左右（报名第 20 天）**的反馈：被问到「为什么你在女生面前不紧张」，他讲了成长经历：

  - 「在女生面前我倒是蛮自信的，其他方面短板很明显。」

  - 学员解释「思路清晰」的含义：以前**对某一类女生只用同一种打法**，现在知道**必须按类型分打法**：
    | 女生类型 | 打法 |

    | 家庭保守型 | **走心** |

## 七、案例③：牵手 APP，三小时确认关系（47:30–58:30）

**认识与节奏**

  1. 「你和我」→「**我们**」：「你喜欢吃汉堡吗？我喜欢，那我们有空一起去吃个汉堡吧。」
  2. 地域拉近：「你是哪里人？」→「这个地方离我还蛮近，有机会我带你去玩。」

- **公薪流（攻薪流）打法示范**：
  - 「我也是，我感觉我们两个还蛮有缘分的。」

  - 她说「怎么跟你聊得这么有缘分」；
  - 晚上情绪波动最大的时候**直接确认关系**。

**异地维持一个月**

## 附录 · 核心结论速记

1. **人设是全场论据的核心**：173cm/150 斤/圆寸/月薪 5000/无车房/刚脱贫县城/农村出身/没去过游乐场——越「差」，越能证明「技术可以替代经济与建模」。
2. **投入极低**：分期付款的**纯线上**私教，从没上过线下课；声称 3 个月在女生身上**花费不到 300 元**，反而多次由女生出钱、出路费、订酒店。
3. **路径唯一性**：把妹三条路（技术/颜值/钱），他只能走技术流，所以只能「硬聊」——把一句话拆成 5–10 个话题，聊到价值观层面。
4. **可复制的聊天模型**：投其所好（吃喝玩乐）→ 用反馈测窗口 → 窗口大就乘胜追击、窗口小就高价值离场 → 0–100 米量化推进 → 升级到「我们」→ 聊男朋友标准/最浪漫的事/生病会不会照顾我。
5. **分类型打法**：保守型走心；夜场型靠外形或付费；女强人靠关注生活+夸赞。「不是投缘，是我在兼容她」。
6. **线上做满，线下只是执行**：见面时间、酒店、亲密细节全部线上预演；线下只要「不断档、不见光死」即可。异地靠每日报备 + 每晚 30–60 分钟电话维持。
7. **平台选择因地制宜**：小县城用**火花**（积木/牵手没人用），省会/大城市用**牵手**，免费课阶段靠小红书查高级饭店充谈资。
8. **临场抗压是关键差异点**：被说「你是谁呀」、被拒绝亲吻、被威胁「告你」、被要求睡地上，他都不慌，靠订酒店、话术转场、卖惨、温柔满足要求层层推进。
9. **心理收益被反复强调**：从自卑被「治愈」、工作有动力、压力有出口、形成正反馈循环；并由此产生「不想一辈子在农村」的阶层跃迁动机。
10. **整场本质是转化漏斗**：案例故事→干货钩子（凌晨 5 点流/三位一体术）→加微信（FXQG458 / FGZ2034 / 公子 680 / 把妹 211）→试听课→私教/门徒。
11. **争议点（记录，不代表认同）**：
    - 「微信确认关系不算搞定，肢体链接才算」的价值观；
    - 按回床上、消解对方离开借口、「凌晨 5 点」等手法，涉嫌违背真实意愿，具有法律风险；
    - 所有数据、案例、截图均由讲者单方提供，**无法独立验证**；主播本人也承认「流量大、要保护隐私」。
