> 整理日期:2026-09-09(第 3 版:按 **100U 账户**重算全部数字;杠杆统一为逐仓 **10x**;新增"每笔交易标准流程"与每日熔断)
> 本笔记整理自 [[以太战法交易直播]] ,保留全部原始思想,重新分组排版,并对笔误与个别算错的数学做了勘误。

## 〇、总纲:先活下来,再谈盈利

> **资金管理比一切技术指标都重要,仓位管理比一切都重要。**
> **错了不重要,我需要的是在一万次交易里面活下来——活下来比盈利更重要。**

- 目标:先活过 **1 万笔交易**。如果 1 万笔交易之后我还活着,就已经非常了不起。
- 复利思维:哪怕单笔只赚 **千分之一**,只要都对,1 万笔复利下来资金可以放大上万倍(理论值)。所以**不要小看小收益**,关键是活到那一万笔。
- 交易系统只能让我**锦上添花,不能雪中送炭**——仓位管理建立在一切基础之上。
- 用**规则去对抗人性**,用人性对抗交易;每次进场都要有自己的逻辑。
- 人不可能预测市场,**指标只是辅助工具**;不必太纠结于抄底摸顶(盈亏同源)。
- 买点好又怎么样呢?**卖点不好,看对了也没用**——任何一笔交易我都要承受交易风险,风控永远排第一位。

## 一、仓位与资金管理(铁律)

### 1. 为什么这么设计(数学基础)

- 目前胜率约 **50%**,计划交易 **5,000~10,000 笔**。
- 50% 胜率 × 5000 次 → **几乎必然会遇到连续 10~15 次亏损**(约 91% 概率会遇到 10 连亏)。
- 从数学角度,交易次数一多,**一定会有连续 9 次亏损**——遇到时我必须确保自己活下来。
- 容错问题:如果仓位大、次数多、杠杆高,破产概率依旧很大,甚至可能全输;宁可小仓慢做,也要保证活下来。
- 所以铁律:**仓位必须扛得住"连续 15 次亏损"而不破产**。

### 2. 核心参数表(记住这三个数字)

| 参数 | 设定 | 理由 |
| --- | --- | --- |
| 单笔风险 | **≤ 2%**(当前 100U = **2U**) | 连亏 15 次只亏约 26%,剩约 74U,还活着 |
| 杠杆 | **逐仓,统一设置 10x** | 100U 够用;强平距离约 10%,容错大;不碰 30x |
| 单笔止损 | **亏损达 2U 就砍** | 不管多看好,止损位到了必须走 |

> 硬上限:开仓前先算最坏亏损——**亏不起 2U 的单子,不做**。

### 3. 完整规则(照做)

**规则 1:每次交易前先算"这笔能亏多少"**

```
账户 100U × 2% = 2U 最大亏损
→ 开仓前算好:止损价在哪?触发止损是否亏损 ≤ 2U?
→ 亏不起 2U 的单子,不做
```

**规则 2:先算仓位,再看杠杆(杠杆是结果,不是设定)**

```
例:做 BTC,现价 78,000,止损 77,500(跌 500 就砍,约 0.64%)
→ 仓位 = 2U ÷ 500 = 0.004 BTC
→ 名义价值 = 0.004 × 78,000 = 312U
→ 逐仓 10x:占用保证金 ≈31U(约账户 30%)
→ 强平价约 7 万附近(距入场约 -10%),远在止损价之外 ✅

速查(账户 100U、单笔风险 2U、逐仓 10x):
止损距离 2%   → 名义 ≈100U → 保证金 ≈10U
止损距离 1.5% → 名义 ≈133U → 保证金 ≈13U
止损距离 1%   → 名义 ≈200U → 保证金 ≈20U
止损距离 0.7% → 名义 ≈286U → 保证金 ≈29U(接近上限)
→ 止损比 0.7% 更近:保证金会超过 30U——减少风险金额,或不做
→ 实际风险只由"2U 公式"决定,与杠杆设置无关;10x 只是保证金工具
```

**规则 3:连亏与错误动作的纪律(最关键)**

```
连亏一定会遇到:
✅ 每笔仍只亏 2U——连亏 10 次账户只回撤约 18%,继续按原计划执行
❌ 禁止"加仓摊平"(那是爆仓根源)
❌ 禁止"感觉要回了就重仓"(情绪化交易)
❌ 禁止锁仓/对冲:方向错了直接止损,不反向开单锁仓(锁仓 = 变相扛单 + 双倍手续费)
❌ 禁止把止损往远离方向移动
```

**规则 4:分批 / 单币种限制**

```
单笔风险 ≤ 2U
同时最多持有 2~3 笔(总风险 ≤ 5~6U)
单币种保证金投入 ≤ 账户 30%(≈30U)
```

**规则 5:节奏与复盘**

```
5,000 次 ÷ 每天 10 次 = 500 天(约一年半)
5,000 次 ÷ 每天 5 次  = 1,000 天(近 3 年)
→ 这是"长期练手",不是短期暴富
→ 每月复盘一次:胜率、盈亏比、有没有违规操作
```

**规则 6:每日熔断(补充)**

```
当天连亏 3 笔(亏 6U)→ 当天收手,不再开新单
→ 复盘当天的每一笔:是系统问题,还是情绪问题?
→ 第二天按原计划继续,不报复性交易
```

### 4. 破产概率测算(勘误后)

```
单笔风险 2%(2U):连亏约 200 次资金才会趋近清零(0.98^200 ≈ 1.8%,剩不到 2U)
——注意:0.98^50 仍剩约 36%,并非"50 连亏就清零"
50% 胜率下,5,000 笔里遇到 50 连亏的概率 ≈ 0(量级 ~0.5^50)
实际最坏情况约为 15 连亏 → 最大回撤约 26%(剩约 74U),仍然活着
→ 这套系统破产概率 ≈ 0 ✅
```

> 勘误说明:豆包原方案中"2%^50 ≈ 0,50 连亏清零"算法有误(把风险率当成了剩余率),结论不变但数字需修正为上述版本。

### 5. 资金升级规则(加码前提)

- **初始资金翻 3 倍之前,单笔可承受亏损不变**:
  - 当前资金 **100U** → 每笔最多亏 **2U**,**300U 之前不加码**。
  - 只有当资金实现 3 倍增长(如 100U → 300U,500U → 1500U),才考虑提高单笔亏损额度。
- **验证门槛**:如果账户从 500U 都做不到 1500U,就不要考虑提高资金量——**先以小试大**,小资金验证出正期望系统,再谈放大。

### 6. 波动率过滤(ATR)

- 用 **ATR 查看波动率**:如果 ATR 一直在低位(市场没有波动),**最好不要交易**——没有波动就没有利润空间,只有磨损。

## 二、市场情绪与进出场系统

### 1. 大盘情绪与选标的(先看大环境)

**① 情绪依据**

- 看**涨幅榜**;以 **BTC、ETH、SOL** 作为大盘的情绪依据。

**② 市场情绪判断(赚钱效应确认)**

- 看**当日涨幅 > 8% 的标的数量**:
  - **数量多** → 整体强势:**只做多,不做空**;
  - **数量一般** → 震荡行情:降低交易频率,**轻仓谨慎**;
  - **数量极少** → 亏钱效应明显:**小仓位做空跌幅榜**。
- 核心:**顺市场情绪,不与大环境做对抗**。

**③ 选标的规则(只做最强)**

- 优先选择**成交量更大**的标的。
- **放弃大部分交易机会**:没有明显优质标的就直接空仓,不要在弱势大盘里找机会,顺势而为。

### 2. 进场方式

- **优先在突破位置做交易**(重点学习突破交易系统);也可以用**底仓做低吸**,但低吸是辅助,不是主要玩法。
- **建仓前必须想好对策**:涨了怎么办?跌了怎么办?哪里加仓?哪里止盈?——我对了有对的应对,错了有错的应对。
- 突破高点的判断以**大周期**为准;斐波那契等工具在**大级别**上更准确。
- 看大周期定小周期:当 **EMA50 下穿 EMA144/169** 时,才有可能出现大暴跌——重点看 **4 小时 EMA 均线**。
- **越接近我止损位的单子越值得做**(止损近、盈亏比高)。
- 每次冲高或下跌,在任意级别做单,先看**是否有 K 线穿过 EMA50 均线**——这一点很重要;出现时做顺势单的胜率很大,**止损放在上一低点**。

### 3. EMA50 示例(4 小时级别)

> 当突然出现上涨或下跌或者大回调的大行情时:**EMA50 线在 4 小时图上第一次被站上**,就要开始重视;
> 后面价格**回踩之后第二次触到 EMA50** 时,就要开始考虑向上突破的可能性。

### 4. RSI 入门玩法(适合中长线)

- **入场:RSI 站上 50 再开始考虑做多**(50 上方偏多区)。
- **止损:放在当前 K 线的顶/底端**(顶底外沿)。
- **止盈:做多时,止盈区放在 RSI 70 以下、50 以上的区间**,并结合点位与 MACD 判断。
- **超买超卖区(RSI > 70 为超买、< 30 为超卖)**配合点位做止损止盈。
- ⚠️ **失效条件**:遇到极端单边行情时,RSI 会持续钝化在超买/超卖区,这套玩法不管用,不要逆势接刀。
- 特点:**盈亏比高,但胜率偏低**,所以适合中长线而非短线。

### 5. 平仓与止盈

- 基础参考:**MACD 作为辅助平仓/止盈工具**。

### 6. 点位与盈亏比(怎么提高盈亏比)

> **点位是解决盈亏比问题的关键。**

- 找**压力位/支撑位附近的止损点**:入场点离止损点、压力点、支撑点越近,止损越小,**盈亏比越高**;
- 入场点离支撑阻力位越远,止损越大,**盈亏比越低**,这种单子不值得做。
- 止盈硬规则:**赚的时候至少拿到 1.5~2 倍于止损的距离再走**(例:止损 2U → 止盈至少 3~4U)。

## 三、止损与心态纪律

### 1. 止损的两个目的

1. **否定自己的交易方向**——市场永远是对的,方向错了必须认;
2. **否定自己的交易时机**——方向可能对,但进场的时机错了也要走。

### 2. 规则约束人性

- 我必须用**规则约束人性**(而不是靠意志力):止损是纪律,不是选择。
- **单次亏损必须在自己能承受的范围之内**,确保每一次亏损都伤不到本金根基。
- **只相信自己的判断**:按自己写下的规则执行;别人的观点和喊单,不改变我的仓位和止损。

### 3. 过度自信 = 离场信号(反人性纪律)

> 原文:"方向错了就一定都错了,如果我内心方向判断超过70,就立马走人"

- **当内心对方向的判断"超过 70 分"(觉得自己稳了),立刻走人**——过度自信往往是反转前兆;
- 参考教训:**之前扛单 ZEC、ETH 的亏损**,就是方向错了不肯认 + 信心膨胀导致的。

### 4. 扛单 = 资金利用率低

- **扛单是资金利用率低的表现**,坚决禁止——资金被套在错误的方向上,等于放弃复利。
- 要学习**复利**:哪怕是千分之一的收益也要重视,不靠单笔暴利,靠"活得久 + 滚雪球"。

### 5. 不预测、不猜顶底

- **盈亏同源**:哪里做多哪里做空都可以是对的,关键不在方向而在管理与执行;
- 指标只是辅助工具,**严格控制仓位管理**,让胜利概率提高——哪怕每笔赢千分之一,积累起来也很厉害;
- 不要执着于抄底摸顶,吃到自己有把握的那一段就够了。

## 四、当前执行计划(100U 起步)

> [!success] 口径已统一
> 资金:**100U**;杠杆:**逐仓统一 10x**;持仓:**单向,不锁仓、不对冲**;该止损止损。

- 起步资金:**100U**
- 目标:**在 5,000 次交易中活下来**(终极考验 10,000 次),慢慢打磨自己的交易系统
- 预估胜率:**50% 左右**
- 盈亏比目标:**≥ 1.5,推荐 1:2**
- **胜率不需要 100%,我需要更重视盈亏比。**
- 周一周二周三波动率大,仓位要小

### 每笔交易的标准流程(照做)

1. **看情绪**:当日涨幅 > 8% 的标的数量 → 强势只做多 / 震荡轻仓 / 极弱小仓空;
2. **选标的**:只做最强(成交量优先);没有优质标的 → 空仓,不勉强;
3. **找点位**:突破位,或回踩 / 穿越 EMA50 的顺势机会;越接近止损位越值得做;
4. **定止损**:放在结构位外侧(上一低点 / K 线顶底),算出止损距离 %;
5. **算仓位**:仓位 = 2U ÷ 止损距离;名义价值 = 仓位 × 价格;
6. **查保证金**:逐仓 10x 下保证金 ≤30U?强平价是否远在止损价之外?
7. **开仓**:单向持仓;同时挂好止损单与止盈(≥1.5 倍止损距离);
8. **执行**:到止损无条件走;不扛单、不摊平、不移动止损;平仓参考 MACD;
9. **收工**:当天连亏 3 笔 → 停手复盘;每月复盘胜率 / 盈亏比 / 违规次数。

### 胜率 50% 时,盈亏比决定盈亏(期望表,单笔风险 2U)

| 盈亏比 | 50% 胜率的单笔期望 | 结论 |
| --- | --- | --- |
| 1 : 1 | 0(白干) | ❌ 不够 |
| 1 : 1.5 | +0.5U/笔 | ✅ 起点 |
| 1 : 2 | +1U/笔 | ✅ 推荐 |

> 50% 胜率 × 盈亏比 1.5 → 每笔期望 +0.5U → 5,000 次 ≈ +2,500U(理论值,未计复利)
> **能不能赚取决于盈亏比(≥ 1.5),能不能活取决于单笔风险(≤ 2U)**——两者都守住,就从"赌徒"变成了"有正期望的系统交易者"。
> **看对看错不重要,重要的是:看对时赚了多少,看错时赔了多少;亏钱的时间越少越好,赚钱的时间越多越好。**离止损位置开仓越近越好,注意盈亏比,平均盈利要大于平均亏损

### 一句话总结

> 我的仓位系统 = **单笔风险 2%(2U)+ 逐仓 10x + 固定止损 + 盈亏比 ≥1.5**。
> 这套系统保证我在 50% 胜率、5,000 次交易下"几乎不可能破产";能不能赚钱,看盈亏比守不守得住。

### 每次开仓前检查清单

- [ ] 这笔最多能亏多少?(单笔 ≤ 2% = 2U)
- [ ] 止损位在哪?触发止损是否亏得起?
- [ ] 仓位算对了吗?(2U ÷ 止损距离)
- [ ] 逐仓 10x?保证金 ≤30U?强平价远离止损价?
- [ ] ATR 显示有足够波动吗?
- [ ] 大盘情绪如何?(强势只做多 / 弱势小仓空 / 震荡轻仓)
- [ ] 标的够强吗?(优先成交量大的;没有优质标的就空仓)
- [ ] 涨了怎么办 / 跌了怎么办的预案都写好了吗?
- [ ] 内心信心是不是已经 > 70?(是 → 离场,不做)
