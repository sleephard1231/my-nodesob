## 00:00–04:30　开场：先搞懂男女看照片的逻辑不同

- 本期两件事：① 点评听众朋友圈照片，指出好在哪、差在哪、怎么改；② 讲「不靠整容、不大改也能立刻变帅」的方法，重点是**照片/本人呈现出的质感**，而不是你本来的长相。
- **男女看照片的逻辑相反**：
  - 男人看女人：看**整体氛围**——有没有「美女模子」，即妆造、发型、穿搭、胸、臀、肤色。
  - 女人看男人：不看你营造的氛围，而是**直接盯几个硬特质**，据此判断你是不是「真帅哥」。
- 为什么女人容易吃到「女性红利」，男人很难：
  - 女人的美**后天可弥补空间极大**——脸大用长发遮颧骨、身材用长裙裹、皮肤黑用粉底、个子矮穿高跟、胸小垫胸贴、臀小垫臀垫。讲者称「目前所有医美手段都能把女人的瑕疵补够」。
  - 而且男人看得不细，整体像就行。
- 男人的帅，不在于服化道，而在于**瘦、面部脂肪轻薄、有下颌线、有帅哥的整体感觉、肩宽、身高**——这些「很难后天伪造」。
- 所以**拍照前必须先定路线**（讲者给出的三条路）：

| 路线 | 要求 | 容错点 |
| --- | --- | --- |
| 纯颜值路线 | 脸必须让妹子心动，必须能对应到某个明星/网红/某一款帅哥 | 背景、服化道可以「low 到极致」 |
| 价值路线 | 让妹子感到你至少 A8 身价、生活方式精彩，且**不是抠搜鬼**——真有钱且大方 | 颜值不是重点 |
| 综合优质路线 | 颜值、价值都不拔尖，但整体质感要**干净、自律、教养好** | 靠质感取胜 |

> 「妹子看到你这张脸，一定能想到某一个明星、某一个网红、某一款帅哥，不然你这张照片就是失败。」

- 案例（02:38–03:09）：某男生下唇略凸、眼睛偏小、**下颌没有拐点、一刀切**——讲者强调「下颌线一刀切过来的，你绝对不是帅哥」；优点是脸上没赘肉，问题是眼睛不够好看、下巴太尖，建议推成方下巴/平下巴增加英气。

## 04:30–08:42　干货一：松弛感

- 提问：小帅与大帅、刚变帅与帅了很久的人，**最明显的第一区别**是什么？答案：**松弛感**。
- 反面示范（04:53）：头很正、眼神呆滞、动作正式、没有表情状态——典型「模板照」。
- 正面示范（05:06–06:42）：敢做正常人不敢做的动作（手插在奇怪位置、微微弓腰、蹲在路边像「拉屎」一样拍），因为他不认为自己在拍照。
- 核心比例（讲者口径）：
  - 不帅的人：<span style="color:red">**90% 精力**花在「怎么拍帅」上</span>；
  - 帅的人：只花 <span style="color:red">**10% 精力**</span>在拍帅，<span style="color:red">**90% 在做自己想做的动作**</span>。
- 为什么刚变帅的人做不到：拍照经历少、不常照镜子、不了解自己的脸。教学现场例子：
  - 让学员「眼睛往右看」，学员整个头转过去；真正的帅哥是**脸几乎不动，眼睛只移一点点**。
  - 让「头歪一点」，学员歪一大截；会拍的人只歪「一点点」。
  - 让「手撑着」，不会拍的人整条胳膊架出去，很丑；会拍的人只微调一点，感觉完全不同。
- 实操建议：拍吃东西就**抓拍**，让对面的人在吃的过程中记录，不要喊「开始了」再摆。
- 松弛感的来源（讲者定义）：
  - **底层逻辑：帅得足够久**，对颜值足够自信，拍照目的性不强；
  - **表面逻辑：以损耗自身颜值为代价换自然**——8 分的长相，愿意拍出 7 分的照片，用 1 分颜值换真实感。
- 结论：没有松弛感，妹子不会默认你是大帅哥；五官不标准但照片松弛自然，效果可能**强过生硬满足美学标准的帅哥**（前提是「不能太低」，照片得先有氛围）。

## 08:42–11:28　案例串讲：生硬照 vs 氛围照

- 08:42–09:59（第一位）：所有照片都生硬、没眼神、没动作、表情不变；只有一张「真的在看窗外」的相对自然。诊断与建议：
  1. 发型是败笔，纹理感不够 → 留长一点、调一点颜色；
  2. 眼睛要做（眼神在脸上的存在感、冲击力不够）；
  3. 皮肤与照片质感偏劣质 → 拍照前妆造准备做足，画质更清晰、更聚焦；
  4. 场景只拍高端场合（平层、餐厅 OK；高尔夫、户外不好）；**「所有不显得人帅的场合都不要拍」**，包括他们已不带学员去的「欧马咖 RC」。

- 10:42–11:28（第三位）：帅哥特征全都有——头小脸小、脖子长、下颌有拐点、鼻梁高；但**下巴太尖**（应推平）、**妆偏重**。全场最大 bug：**眼神呆滞、不含任何情绪**。
  - 讲者判断：这种照片妹子不会认定你是帅哥，**只会认定你是男模**。

## 11:28–15:00　干货二：眼神（拍照第一顺位）

| 眼神类型 | 特征 | 代表 |
| --- | --- | --- |
| 温柔含情型 | 没有明显情绪，正常注视你、略带温柔，但有种说不出的魅惑，「像校花姐姐看着你」，让人心跳加速 | 示范照片 |
| 媚型 | 好像没用力、眼神迷离，但眼睛很有神 | 示范照片 |
| 痞帅型 | 坏坏的、不羁 | 贾斯汀·比伯（ASR 作「贾森比伯」） |
| 剑眉星目型 | 情绪复杂：既像凶狠盯你、又像放电、又像温柔，有压迫感 | 肖战、杨洋（讲者称「古装天花板」） |

- **普通人的死穴**：不用力 → 眼睛像睡着、眯着；一用力 → 瞪眼、眼珠凸。做不到「眼睛不张开但很有神」。
- **反差原则**：长得奶，只要眼神一换，妹子照样觉得你 man；五官再硬朗，眼神一变也能变可爱。**「乖中有 man，man 中有乖，女中有男，男中有女」**最好。
- 判定标准：<span style="color:red">**眼神 + 松弛感 = 妹子判定你是不是大帅的最重要标准**</span>。女人的「我很看感觉」是真的——感觉＝松弛感 + 眼神到位。
- 「眼神 P 不来」：轮廓和眼神必须到位；五官再帅但眼神不对，就达不到吸引作用。
- 14:30–15:00 补充：有的男生整体已比普通人好、已经有氛围，但放在「见过真帅哥的女人」面前，一眼就被看穿不是大帅——所以「跟自己比提升了」不等于在市场上能拿到红利。

## 15:00–19:41　连续点评：风格错配是最大问题

- 15:00–16:38（「四不像」案例）：鼻子小、嘴凸、眼神不对。讲者判断其外形既没有狼狗的拽、也没有奶狗的氛围、又缺阳刚之气，**妹子无法归类**。
  - 他能吸引到的（讲者口径）：5 分左右的女性、年纪偏大的女性、软件上滑到的少妇；「有质感的女人」和心细的女生（尤其艺术生）基本与他无关。
  - 改造方向：头发不动；眼睛必须做项目；五官思路**不是做减法而是做加法**，要更硬朗。20 岁以上、皮肤不白、卧蚕不深、眼睛不大没神，走不了奶狗路线。
- 16:40–17:23（「朋友圈还不错」案例）：被当场否定——「眼睛瞪得跟驴眼睛一样」。由此引出**丁真**：讲者称「没有内涵却极受女性喜欢的人，颜值一定非常牛」。
- **衣品捷径（干货）**：去认识男模，发个红包，直接要「你上班最常穿的那一身 + 当天发型」，照着穿，比自己在网上摸索有效得多。
- 17:26–19:41（瘦削型案例）：优点是松弛、自然、电梯里随手拍的动态感；缺点是**瘦得太极端**——脸上完全没肉、没有皮相、全是骨相。
  - **「精致不是每个人都适合」**：他适合卫衣、嘻哈、丛林/海边/马路这类街头感；一旦放进高光打满的高端餐厅，视觉重心落到脸和身材上，**身体结构撑不起照片质感**。
  - 类比：清纯女生去宝格丽晚宴戴一亿珠宝撑不起来；大气女人穿 JK 也没那个味。
  - 可用的：随意的、动的、电梯里的；不可用的：近距离、强光、高端场合。

## 19:41–22:14　干货三：笑容

- 提问：除了松弛感、眼神，还有一个让妹子心动的区别是什么？——**他们都没有笑容**。
- 讲者观察（20:04）：「所有女人的照片都在扮骚，所有男人的照片都在扮酷」，共同缺失的是**笑容**、青春洋溢、整张脸往上走的状态。
- 案例链：
  - 明星顶流：**肖战**。讲者认为静态的肖战可以找到「代餐」，但他有两样无人能替：**笑**与**眼神**（提到抖音「肖战笑眼杀」，ASR 作「笑龙杀」）。「最吸妹子的几个特质他占了俩，还长在同一张脸上」。
  - 网红颜值顶流：**香菜**；往下 **皮皮猪**、**王不染**——三人无一例外「笑起来好看」。
  - 全球偶像：贾斯汀·比伯、权志龙——「只要能让全世界都喜欢他，笑的一定好看」。
- 结论：不管走哪条变帅路线，<span style="color:red">**总得塑造一个「心动点」**</span>——笑容好看、眼神好看、或动作松弛，关键时刻施展出来，妹子就默认你是帅哥。
- 讲者承诺：朋友圈具备这三点，妹子会认为你帅，「哪怕你不帅」；效果胜过整容脸和天天摆 pose 拍飞机大炮的人。

## 22:14–26:29　骨相标准：先骨架，后五官

- 22:14–23:32（潜力案例）：眼睛有问题（但贴了双眼皮贴后尚可）、发型有问题、鼻翼略宽；优势是**下颌连接处结构优越**，保住了颜值下限。穿纯色素 T 加分，花里胡哨减分，照片质感极差。讲者反复劝其报私教，「上限很高」。
- 23:32–26:05 **帅哥侧脸判定法**（可直接自测）：
  1. 把五官挡住，只看**额头—眉弓—面中—下颌—下巴**这条线；
  2. 颧骨、颧弓不能高，要**流畅**过渡；
  3. 面中不能有赘肉：不垂、不抛、不厚、不多，要**往里凹**；
  4. 这条线必须清楚；
  5. 下颌处**必须有拐角**；
  6. 下巴必须是**平下巴**：圆下巴/尖下巴只有一个承重点，平下巴左右各一个承重点，加上下颌转角与衔接处，整张脸应有「四五个转折点」。
- 反例自证：鹿晗被说「娘」，但下颌线具备帅哥共性——「娘是五官风格娘，骨架仍是帅哥骨架」。
- 操作顺序（25:47）：<span style="color:red">**先把颧骨—颧弓—下颌线—下巴这一整块做到极致，再研究五官**</span>。「能花钱搞定的事都不难；花钱改变不了的才崩溃」。拐角突出度不够可以打针解决。
- 26:05 边界声明：讲者自称不专业于医美，「我讲的所有美学，是基于**在女人那儿有效**的东西」；男人认可的帅不重要——「我让男人觉得我帅没有用，我又不卖屁股」。

## 26:29–29:30　颜值顺位：妹子看你的时间轴

| 阶段 | 时长 | 她看什么 |
| --- | --- | --- |
| <span style="color:red">第一眼</span> | 3–5 秒 | <span style="color:red">**身高 + 比例**</span>（头小、脸小、脖子长且细、肩宽、腿长、腰窄、整体偏瘦） |
| 落座开始聊天 | 3–5 秒之后 | **发型、衣品、整体脸型**有没有帅哥感觉 |
| 熟悉、敢对视交流 | 之后 | **五官**，一直看到发生关系为止 |
| 发生关系之后 | — | 形象归零，不再重要 |

- 身高门槛（讲者口径，指「呈现出的感觉」）：公共场合、人群密集处想出众，<span style="color:red">**低于 1.78 m 很难被认为帅**</span>；一对一固定空间见面，<span style="color:red">**1.74–1.75 m 是底线**</span>。

- 这套顺位来自讲者自称接触大量「瘸腿选手」的经验：氛围好但五官差、五官好但个子矮、衣品时尚但没整体高度——由此反推「真正起作用的点在哪」。

## 29:30–36:14　男女策略差异（讲者自称「全场最干货」）

- 先回应「男人看女人顺位」：讲者认为约 50% 男人是纯颜控只看脸，50% 看整体感觉。
- **女性建设思路（假设自己是女人）**：80% 精力花在脸上，20% 花在风格上；身高、身材、仪容、走路姿势都不重要。
  - 理由：身材好只会吸引「臭屌丝」，对女人是减分；高质量男人只看脸或看内涵。
  - 「健身房里的女人」论证：在中国任何健身房，天天苦练身材的普通女性，几乎见不到 5.8 分以上（讲者以其颜值体系为准），并举「花小龙老婆王老师」为参照。
- **男人建设思路**：男人要的是**冲击力**、最低成本、快速推进；五官的作用发生在「漫长相处」里，而男人不需要漫长——「女人是越长越好，男人是越短越好」。
  - 所以：<span style="color:red">**男人要第一眼暴帅，女人要耐看；男人可以越看越丑，女人必须越看越好看**</span>。
  - 「男人能谈恋爱，不如会泡妞有魅力；女人天天被男人睡，不如能谈一个恋爱有魅力。」
- <span style="color:red">**建设的第一原则：让妹子快速爱上你，而不是慢慢爱上你**</span>。慢慢爱上你的东西（内涵、学历）有无数可复制的代餐，且这些特质在短期施展不出来、在长期又不是最好使的（长期最好使的是花时间、培养感情、花钱）。
  - 结果只有两种才算有效：① 一眼「爆杀」，看到你就想睡；② 一眼被判定「适合做老公」。
  - 最惨的是中间态：短期不够帅、不够眨眼，长期又不能提供实在价值——「很鸡肋」。
- **否定「长期主义」**：讲者称这个词「很扯蛋」。其性别断言：「女人是没有爱情的，谁对她好她跟谁走；男人深情又多情；女人爱你时爱到骨子里，发现你差点意思就立刻绝情。」

## 36:14–41:54　爱情＝滤镜；长期关系是消耗战

- **滤镜论**：任何长期关系里，再优秀的人也会失去滤镜。两人天天一起洗澡、吃饭、生活，会产生无数减分项（啤酒肚、打游戏、不洗袜子内裤、吃油腻），「你比不上男模对她的吸引力」。人跟人「不能太近，也不能太远」。
- **约会＝感觉**：两人喝酒时说的「我只谈过两段恋爱」「第一次见你就心动」「你是我最喜欢的人」都是氛围话术；妹子照片 7 分真人 3 分，你也会自动把现实颜值替换成朋友圈的样子。
- 喜欢一个人的机制：自己给他加滤镜 → 形成习惯、依赖、熟悉感。「你喜欢的不是对方，是跟对方说话的状态」——「你跟一条狗聊三个月，难道一点感觉没有？」
- **婚恋＝交易**：长期关系的实质是工作、收入、房产、贷款、父母职业这些「实际用处」；「要不然是有用合作，要不然是感觉」。讲者认为国男幻想的「爱情」不存在。
- 关系后半段是「苟延残喘」：滤镜褪去后靠「培养感情的时间跑赢滤镜褪去的时间」，加上没有更好选择、多一事不如少一事，才勉强守住。
- 性别观察（讲者口径）：
  - 男人的占有欲＝在意女人的穿搭与意识形态；
  - 女人的占有欲＝挑刺、说教、教男人做事、找毛病。
- 亲身例子（39:54–40:54）：他习惯把一次性隐形眼镜攒 5–10 盒再扔、垃圾桶一周一换、床单被套一月两次；女伴坚持「摘一个丢一个」、天天换垃圾袋、三天换一次床单，并指责他「不爱卫生、不懂生活」。后来去女方家发现**她家比他还脏还臭**——结论：她不是爱干净，是「教你做事、指挥你、挑刺」很爽，是在关系里刷存在感。
- 收束：基层男女到结婚那天彼此根本不熟；中产情侣互相嫌弃又互相凑合——「你不觉得很崩溃吗？」

## 41:54–44:20　小县城、幸福定义与「国男」

- 对「小县城怎么出击」：讲者直接劝退——「小县城没救」，game、赚钱、泡妞都达不到很高程度；「让我在一个地方呆着，跟死了差不多」。
- **幸福公式**：`幸福 = 自由程度 + 亲密关系 + （花钱 ÷ 工作时间）`；工作时间越少、花钱越多、亲密关系越多，越自由越幸福。核心是「自由地做自己热爱的事」。
- 对「国男」的批评：一切努力的原动力只是「活着就行」——饿不死、有地方住、能呼吸，没有精神追求。
  - 反问：你活着是为了自己吗？现在做的哪件事是为自己？父母说「都是为你好」，讲者认为背后是「在朋友面前炫耀、怕在老头老太太中丢人」。
- 全场价值主张：「**让各位兄弟对美好生活充满向往，可以为自己而活，把时间精力、注意力花在自己身上**。」

## 44:20–47:18　收尾：评价、喷子与课程

- 回应「教约妹的低人一等」：讲者称自己是「知识付费」，职业不分贵贱；用周杰伦类比——「你管别人会什么，有一个东西就行了」。
- **任何人对你的评价都不能往心里去**：所有观点都是对方站在自己角度的判断。
  - 喷你的人动机分类：① 同行——为了挣钱，喷完必接一句「想学加我微信」；② 国男——觉得你抢了他的妹子；③ 吃瓜群众——为了站道德制高点。
  - 讲者结论：喷子都是「最自私、最龌龊的小人」，不要浪费时间在不能让你爽、不能给你好处的人身上。
- 对「诈骗」指控：称半个月前已起诉，杭州仲裁委的快递还没到，「我们都是文明人，直接走法律手段，不狗咬狗」。

## 附录 · 核心结论速记

1. 拍照前先定路线：**颜值 / 价值 / 综合优质**，三条路的投入点完全不同。
2. 大帅的第一特征：<span style="color:red">**松弛感**</span>——90% 精力做自己，10% 精力拍帅；用一点颜值换真实。
3. 第二特征：<span style="color:red">**眼神**</span>——不张开却有神，含情/媚/痞/剑眉星目，P 不出来，优先级最高。
4. 第三特征：<span style="color:red">**笑容**</span>——所有顶流都笑起来好看，必须给自己造一个「心动点」。
5. 骨相优先于五官：挡住五官看侧脸线，颧弓流畅、面中内凹、下颌有拐点、平下巴双承重点。
6. 颜值顺位：<span style="color:red">3–5 秒看身高比例</span> → 落座看发型衣品脸型 → 熟了才看五官 → 发生关系后归零。
7. 发型是身高之外的第一项，衣品最快解法是直接抄男模。
8. 风格要匹配场景：瘦削/街头感的人别硬拍强光高端餐厅；「精致不是每个人都适合」。
9. 男人建设要「<span style="color:red">第一眼暴帅</span>」，不要设计「让妹子慢慢爱上你」的路径。
10. 讲者否定长期主义与「爱情」：短期是感觉与滤镜，长期是交易与消耗。
